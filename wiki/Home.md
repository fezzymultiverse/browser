# Festers Browser

A private, security-first mobile browser for Android. The whole app is one HTML file (`www/index.html`) packaged with Capacitor, plus native Java plugins. Mascot: Bojack.

- Licence: MIT
- Current version: see [[Changelog]]
- App ID: `com.fezzy.festersbrowser`
