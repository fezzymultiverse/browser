# Features

## Security
- Shields and tracker protection with a live counter
- NoScript mode with a per-site allow list
- HTTPS-only (falls back to http for sites with no working HTTPS and remembers the host)
- Threat protection and VPN guard, each with an on/off switch
- Certificate handling: repairs incomplete chains using the certificate's AIA field and validates against the phone's trust store; forged or self-signed certificates still fail
- Cookie control: Allow all, Block third-party, Block all
- Security dashboard with a live posture score

## Privacy and data
- Burner windows (private tabs) with isolated storage and no history
- Scorch and Burn to wipe site data (the browser's own bookmarks, notes and vault are kept)
- Encrypted password vault with TOTP, generator and CSV import
- Breach checker (Have I Been Pwned, k-anonymity)
- Encrypted `.festers` backup and full-setup zip backup; nothing leaves the phone

## Browsing
- Tabs, pinning, groups, recently closed tabs, bookmarks, collections, history, bangs
- Back and Forward with a per-tab list
- Find, zoom, translate, reading mode, desktop site, offline pages
- Downloads manager with Festers' own downloader as a fallback
- Media player and Media Downloader extension

## Tools
- DNS-over-HTTPS lookup, Private DNS hostnames, VPN verification
- Notepad, extensions (Wayback, Archive.today, VirusTotal, WHOIS, SSL Labs, DNS check, custom)
- Groq AI assistant (bring your own keys)
- Device dashboard (battery, RAM, network, storage, CPU)

For the honest limits of each feature, see [[Security Model]] and the README.
